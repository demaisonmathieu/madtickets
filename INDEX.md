`getAllTodos()` - Récupérer toutes les todos\n- `addTodo(text)` - Ajouter une todo\n- `addTicket(data)` - Créer un ticket\n- `updateTicket(id, updates)` - Mettre à jour un ticket\n- `getSprintsByProject(projectId)` - Récupérer les sprints\n- `getAllSprints()` - Récupérer tous les sprints\n\n### Vue Router\n- Navigation vers détail ticket : `/tickets/{id}`\n- Navigation vers détail tâche : `/tasks/{odooId}`\n- Navigation vers projet : `/projects/{id}`\n\n### Stockage local (IndexedDB)\n- Table `todos` : texte, date, statut\n- Table `tickets` : titre, sprint, projet\n- Table `sprints` : statut, projet, dates\n\n## 📱 Responsivité\n\nTous les éléments ajoutés sont responsifs :\n- ✅ Checkboxes accessibles au mobile\n- ✅ Boutons redimensionnables\n- ✅ Formulaires
