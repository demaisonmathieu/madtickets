## 🎯 POINTS D'ACCÈS (5 façons d'utiliser)

### 1️⃣ **TicketsList.vue** - Créer + ajouter ensemble
```
Tous les Tickets → + Nouveau Ticket → Cocher options → Enregistrer
→ Todo + Sprint créées automatiquement
```

### 2️⃣ **ProjectDetail.vue** - Dans le contexte du projet
```
Projets → Sélectionner → + Nouveau Ticket → Cocher options
→ Ticket + Todo + Sprint au projet
```

### 3️⃣ **TicketDetail.vue** - Ajouter ticket existant
```
Ticket → 👁️ Voir → 📋 ou 🏃 boutons
→ Ajouter à todo ou sprint
```

### 4️⃣ **OdooTaskDetail.vue** - Convertir tâche Odoo
```
Tâche Odoo → 👁️ Voir → 🏃 Ajouter au sprint
→ Ticket créé + lié + ajouté au sprint
```

### 5️⃣ **OdooTasksList.vue** - Todo rapide
```
Tâche Odoo → 📋 Todo → Todo créée
```
