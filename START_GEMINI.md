# 🚀 DÉMARRER AVEC GOOGLE GEMINI

## ⚡ Quickstart (5 minutes)

### 1. Obtenez une clé API (1 min)
```
https://aistudio.google.com/app/apikey
→ Cliquez "Create API Key"
→ Copiez la clé
```

### 2. Configurez Gemini (2 min)
1. Ouvrez l'app → **Administration** → **🤖 Assistant IA**
2. **Provider** → **Google Gemini**
3. **API Key** → Collez votre clé
4. **Modèle** → `gemini-2.0-flash` (recommandé)
5. Cliquez **"💾 Enregistrer"**

### 3. Testez (1 min)
1. Section **"🧪 Tester l'agent IA"**
2. Entrez: "Que dois-je faire en priorité?"
3. Cliquez **"🚀 Lancer un test"**
4. Voir: "✅ Google Gemini opérationnel"

### 4. Utilisez (1 min)
1. Allez **"🤖 Assistant IA"** (menu principal)
2. Cliquez **"🧠 Générer mes priorités"**
3. Profit! 🎉
