# 📊 Diagrammes de flux - Fonctionnalité \"Ajouter à Todo/Sprint\"\n\n## 🎯 Flux global\n\n```\n┌─────────────────────────────────────────────────────────────┐\n│         Créer / Modifier Ticket ou Tâche                    │\n└────────────────┬────────────────────────────────────────────┘\n                 │\n        ┌────────┴────────┐\n        │                 │\n   Créer Nouveau      Ajouter Existant\n   (Formulaire)      (Détail/Liste)\n        │                 │\n        ├─ TicketsList    ├─ TicketDetail\n        ├─ ProjectDetail  └─ OdooTaskDetail\n        │\n   ┌────┴──────────┐\n   │               │\n  Todo?         Sprint?\n   │               │\n   ↓               ↓\nCrée Todo    Ajoute SprintId\n   │               │\n   └───┬───────────┘\n       │\n       ↓\n   Confirmation\n   \"✅ Ticket créé\n    (todo + sprint)\"\n       │\n       ↓\n   Formulaire\n   Réinitialisé\n```\n\n## 🔄 Flux détaillé : Créer ticket avec options\n\n### TicketsList.vue\n\n```\nClic \"+ Nouveau Ticket\"\n    ↓\nAffiche formulaire\n    ↓\nUtilisateur remplit :\n├─ Projet\n├─ Titre\n├─ Description\n├─ Statut\n├─ Priorité\n├─ ☑️ Ajouter à la todo\n└─ ☑️ Ajouter au sprint\n    ↓\nClic \"Enregistrer\"\n    ↓\nsaveTicket() appelée\n    ↓\nExtrait options :\n├─ formOptions.addToTodo → booléen\n└─ formOptions.addToCurrentSprint → booléen\n    ↓\nDétermine sprintId :\n  if (addToCurrentSprint)\n    → sprintId = currentSprintForSelectedProject?.id\n  else\n    → sprintId = null\n    ↓\nCrée ticket avec db.addTicket()\n    ↓\nSi addToTodo === true :\n  ├─ Génère texte : [TICKET] {titre}\n  ├─ Vérifie pas de doublon\n  └─ db.addTodo()\n    ↓\nRecharge données :\n  ├─ loadData()\n  └─ loadTodos()\n    ↓\nAffiche confirmation :\n  \"✅ Ticket créé (todo + sprint en cours)\"\n    ↓\nCancelForm() :\n  ├─ Réinitialise form\n  ├─ Réinitialise formOptions\n  └─ Ferme formulaire\n```\n\n## 🎯 Flux détaillé : Ajouter ticket existant\n\n### TicketDetail.vue\n\n```\nAffiche ticket detail\n    ↓\nloadSprints() + loadTodos() au montage\n    ↓\nCalcule propriétés :\n├─ currentSprint = sprint actif le plus récent\n├─ todoItem = cherche todo du ticket\n└─ isInCurrentSprint = vérifie si dans sprint\n    ↓\nAffiche boutons conditionnels :\n├─ 📋 Si !todoItem\n│    └─ addToTodoList()\n│       ├─ Génère texte : [TICKET] ou [TICKET ODOO #id]\n│       ├─ Vérifie pas de doublon\n│       └─ db.addTodo()\n│\n└─ 🏃 Si currentSprint && !isInCurrentSprint\n   └─ addToCurrentSprint()\n      ├─ Récupère currentSprint\n      ├─ db.updateTicket(id, {sprintId})\n      └─ Recharge tickets\n    ↓\nAffiche état après action :\n├─ \"• Dans le sprint en cours\"\n└─ \"• Planifié en todo le [date]\"\n```\n\n## 🧩 Flux détaillé : Ajouter tâche Odoo\n\n### OdooTaskDetail.vue\n\n```\nAffiche tâche Odoo detail\n    ↓\nloadSprints() au montage\n    ↓\nCalcule taskLinkedTicket :\n  Cherche ticket avec titre :\n  [TÂCHE ODOO #{odooId}] {taskTitle}\n    ↓\nAffiche bouton 🏃 si currentSprint\n    ↓\nClic \"Ajouter au sprint en cours\"\n    ↓\naddTaskToCurrentSprint() :\n    ├─ if (!taskLinkedTicket)\n    │  └─ db.addTicket({\n    │     title: [TÂCHE ODOO #id] Title,\n    │     projectId,\n    │     sprintId,\n    │     ...\n    │   })\n    │\n    └─ else\n       └─ db.updateTicket(id, {sprintId})\n    ↓\nAffiche confirmation\n    ↓\nRecharge tâches du projet\n```\n\n## 📊 Diagramme d'état - Créer ticket\n         ├─ Action 2 : Aller à todo, créer\n         ├─ Action 3 : Aller au sprint, ajouter\n         └─ Temps : ~3-5 minutes\n```\n\n### APRÈS - Processus optimisé\n\n```\nVouloir ajouter ticket au sprint + todo\n         │\n         ├─ Cocher 2 options\n         ├─ Cliquer Enregistrer\n         └─ Temps : ~30 secondes\n\n         = 90% plus rapide ! 🚀\n```\n\n## 📈 Matrice de
